# RCON Scheduler Core
An app that provides an easy way to schedule RCON commands.

Customizable using [yaml example config](./configs/core.example.yaml)

## Docker
```sh
docker pull ghcr.io/notweuz/rcon-scheduler-core:0.4.1
```

## Go Module
You can use this project as Go module as well!
```sh
go get -u github.com/notweuz/rcon-scheduler-core
```
